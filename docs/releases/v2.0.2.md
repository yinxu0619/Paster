## macOS 更新

- **呼出动画可选**：新增顺滑（默认）、弹性、淡入、关闭四种效果，以及独立的列表动画开关；遵循系统“减少动态效果”设置。
- **卡片选择更稳定**：在可见候选之间切换时保持整排位置，只有到达边缘才滚动；反向选择不再强制居中。
- **恢复滚轮快速选择**：修复高精度／平滑滚轮被误认为触控板的问题。上下滚动选择候选，快速滚动可跨多个候选；左右滑动保留连续浏览与惯性滚动。
- **跨屏与历史列表性能改进**：复用面板内容与缩略图缓存，原图独立存储并按需加载，改善跨屏呼出、图片历史和删除操作的响应。
- **存储管理**：设置页新增存储统计、整理空间和清理缩略图缓存。

## 下载与安装

- **macOS 14.0+，Apple Silicon（arm64）**：下载 `Paster.zip`，解压后将 `Paster.app` 放入“应用程序”。请先退出旧版，再替换并重新打开。
- **Windows x64**：本次未发布 Windows 安装包，继续使用 [v2.0.1 Windows 版](https://github.com/yinxu0619/Paster/releases/tag/v2.0.1)。本页新增的动画与输入改动针对 macOS。
- `SHA256SUMS` 提供 macOS 压缩包的 SHA-256 校验值。
- 首次安装及权限说明见 [macOS 安装说明](https://github.com/yinxu0619/Paster/blob/v2.0.2/README.zh-CN.md#macos-140)。

通过 251 项 macOS 回归检查，以及全宽面板的键盘导航、边缘滚动、反向选择、Home/End 和四种呼出效果检查。滚轮精度、累计位移、方向与手势阶段由输入逻辑测试覆盖；不同鼠标驱动和触控板的实际手感仍需设备实测。
