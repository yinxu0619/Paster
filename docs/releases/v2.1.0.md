## macOS 更新

- **动效与性能模式**：设置新增「特效优先 / 均衡（默认）/ 响应优先」三档，一键在好看与跟手之间切换；呼出效果、列表动画、按住方向键动画、悬停渐变、选中阴影也可单独调整。实测宽屏上触控板滚动时，「均衡」的主线程占用约为「特效优先」的三分之一。
- **新呼出效果**：新增「果冻」（落位时带挤压回弹）和「从边缘滑出」（整块面板从屏幕边缘滑出）。
- **修正呼出方向**：底部横向条此前是从上往下进入的，现在所有效果都从停靠的边缘进入。
- **横向条高度实时预览**：拖动设置里的高度滑杆时，屏幕上按真实位置与大小显示横向条的范围，松手后淡出。
- **面板更顺滑**：去掉每次刷新的重复计算，固定卡片尺寸，长文本只排版可见部分。呼出面板不再切换前台应用和菜单栏，呼出后第一帧的主线程耗时从 22–31ms 降到 6ms 以内；粘贴改为等原应用回到前台后再发送，不再固定等待 120ms。
- **修复**：
  - 按住退格键不再连续删除多条记录，一次只删一条；⌦ 也可以删除。
  - 录制热键时切到其它窗口不再拦截那里的按键；⌘C、⌘V 等系统保留组合会被拒绝。
  - 按 Esc 收起面板后，焦点会回到原来的应用。

## 下载与安装

- **macOS 14.0+，Apple Silicon（arm64）**：下载 `Paster.zip`，解压后将 `Paster.app` 放入「应用程序」。请先退出旧版，再替换并重新打开。
- **Windows x64**：本次未发布 Windows 安装包，继续使用 [v2.0.1 Windows 版](https://github.com/yinxu0619/Paster/releases/tag/v2.0.1)。
- `SHA256SUMS` 提供 macOS 压缩包的 SHA-256 校验值。
- 首次安装及权限说明见 [macOS 安装说明](https://github.com/yinxu0619/Paster/blob/v2.1.0/README.zh-CN.md#macos-140)。

## English

macOS update with **Motion & Performance** modes (Effects / Balanced (default) / Responsive) plus per-effect toggles. On a wide display, Balanced uses about a third of the main-thread time of Effects while scrolling with a trackpad. Two new entrance effects, **Jelly** and **Slide from Edge**. Bottom bars now enter from the bottom edge (they used to enter from above). The bar-height slider shows a live on-screen preview of the bar while you drag.

The panel is smoother: it no longer activates Paster or switches the menu bar when it opens (main-thread time for the first frame drops from 22–31ms to under 6ms), and pasting waits for the original app to come forward instead of sleeping a fixed 120ms.

Fixes: holding Backspace deletes a single item instead of several, and Forward Delete works too. The hotkey recorder no longer swallows keys in other windows and rejects reserved shortcuts such as ⌘C. Esc returns focus to the previous app.

Download `Paster.zip` for **macOS 14.0+ on Apple Silicon (arm64)**. Quit the previous app before replacing it. Windows users should continue using the [v2.0.1 Windows package](https://github.com/yinxu0619/Paster/releases/tag/v2.0.1).
